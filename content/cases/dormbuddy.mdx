# Dormbuddy: Revolutionizing Student Living Experience

<TechStack technologies={["Django", "PostgreSQL", "HTML/CSS/JS", "NGINX", "SEO", "Analytics"]} />

## The Challenge

Exchange students arriving at universities face a common problem: they need essential dorm items for their short stay but don't want to purchase everything new only to discard it months later. This creates:

- Financial burden on students with limited budgets
- Environmental waste from single-use purchases
- Logistical challenges of acquiring essentials in an unfamiliar country
- Storage issues when leaving at semester's end

## Our Solution

As Co-Founder and CTO of Dormbuddy LLP in Singapore, I developed a comprehensive e-commerce platform that addressed these challenges by offering rental services for dorm essentials.

### Complete E-commerce Platform

I built the entire e-commerce store from scratch, focusing on creating a seamless experience for international students who might be unfamiliar with Singapore:

- User-friendly product browsing with detailed descriptions
- Simple rental duration selection
- Streamlined checkout process
- Secure payment processing
- Automated rental period tracking
- Delivery scheduling system

<Callout type="info" title="Engineering Challenge">
One of our biggest technical challenges was creating a dynamic inventory management system that could track items through their complete rental lifecycle - from warehouse to student and back again - while maintaining accurate availability for new bookings.
</Callout>

```python
# Django view for processing payments
def process_payment(request):
    # Validate payment details
    payment_data = validate_payment_form(request.POST)
    
    # Create order in database
    order = create_order(
        user=request.user,
        items=get_cart_items(request),
        delivery_date=payment_data['delivery_date'],
        rental_duration=payment_data['rental_duration']
    )
    
    # Process payment through payment gateway
    payment_result = payment_gateway.process_payment(
        amount=order.total_amount,
        currency="SGD",
        payment_method=payment_data['payment_method'],
        customer_details=payment_data['customer_details']
    )
    
    if payment_result.is_successful:
        # Update inventory availability
        update_inventory(order.items)
        
        # Send confirmation emails
        send_order_confirmation(order)
        
        # Schedule delivery
        schedule_delivery(order)
        
        return redirect('order_confirmation', order_id=order.id)
    else:
        # Handle payment failure
        return render_payment_error(request, payment_result.error)
```

### Technical Architecture
The platform was built with a pragmatic approach to technology, balancing functionality, development speed, and reliability:

- **Backend**: Django framework for rapid development and robust features
- **Database**: PostgreSQL for reliable data storage
- **Frontend**: Custom HTML/CSS/JS for optimized user experience
- **Server**: NGINX for high-performance web serving
- **Deployment**: Manual deployment pipelines for reliability
- **Monitoring**: Real-time system monitoring for uptime and performance

### Business Impact
Dormbuddy had significant impact for both our business and our student customers:

- For Business: Generated over $10,000 SGD in revenue with minimal transaction costs
- For Students: Saved an average of 70% compared to buying new items
- For Environment: Reduced waste by reusing items across multiple semesters
- For Universities: Provided a valuable service that enhanced student experience

<Callout type="success" title="Financial Efficiency">
By developing our own e-commerce platform instead of using third-party solutions, we were able to process payments with minimal transaction fees - just $5 total cost over $10,000 in transactions, representing a 99.95% cost efficiency.
</Callout>
